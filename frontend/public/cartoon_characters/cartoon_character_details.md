# Nano Banana — Cartoon Character Prompt Library

## Purpose

This document contains production-ready prompts for generating reusable 2D cartoon character sheets using Nano Banana.

These prompts are optimized for:

* Animation pipelines
* Remotion workflows
* Lip-sync animation
* Expression generation
* Character consistency
* Sprite sheet generation
* Cartoon video production

Each prompt generates:

* Base neutral pose
* Multiple expressions
* Mouth shapes for lip-sync
* Hand poses
* Head angles
* Animation-ready character sheets

# Remotion Integration Tips

* Export PNG assets with transparent background.
* Separate eyes and mouth layers if possible.
* Keep consistent scaling.
* Use front-facing base pose.
* Generate idle poses separately.
* Maintain same lighting across all sheets.

---

# Production Tips

* Keep character silhouette readable.
* Avoid over-detailed textures.
* Prioritize strong facial expressions.
* Use exaggerated emotions for animation.
* Ensure consistent eye placement.
* Maintain same body proportions.
* Use clean spacing between expressions.
* Prefer flat colors for easier animation.

# LIP-SYNC OPTIMIZATION

## Rule Set

* Break dialogue into phoneme-friendly chunks
* Avoid long sentences (>8 sec)
* Prefer short emotional bursts
* Sync mouth shapes per vowel sound

---

# EMOTION-BASED AUDIO TRIGGERS

| Emotion | Audio Type                |
| ------- | ------------------------- |
| Happy   | Light tone, higher pitch  |
| Angry   | Sharp tone, louder volume |
| Sad     | Lower pitch, slower pace  |
| Shock   | Sudden volume spike       |
| Funny   | Comedic timing pauses     |

# FINAL PRODUCTION PIPELINE

1. Generate character image sheet (Nano Banana)
2. Generate voice via TTS prompt
3. Split audio into emotion segments
4. Sync mouth shapes in Remotion
5. Add SFX from libraries
6. Composite final animation
